This skill retrieves various metadata attributes for financial publications, focusing on sources like the U.S. Treasury. Key functions include obtaining publication dates and additional relevant information.

### Reusable Rule
- Access and interpret metadata attributes accurately to enhance financial data availability.

### Examples
- Retrieve publication dates for reports from the Treasury Department.
- Access author information and publication formats for economic analysis documents.
